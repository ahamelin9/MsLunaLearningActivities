# The styles before the redesign (audit, 2026-10-08)

What the design system replaces. This was the appendix of the old
`docs/design-standards.md`, taken from the code and the first `ui:shots` set,
with a recount from 2026-10-10 below it. It's kept as a record, not as a
standard.

## Two looks

- The tablet shell, Settings, Trophies and Grade Select used a slate-and-purple
  OS style (`src/styles/_variables.scss`) and an emoji owl.
- The reading app used warm paper and wood
  (`apps/reading/engine/_world.scss`) and the drawn owl. It had its own purple
  as well.

## Scattered values (2026-10-08)

| What | Count |
|---|---|
| Stylesheets | 24, 5,348 lines (534 of them in a never-imported `App.css`) |
| Unique hex colours | 185, plus 258 `rgba()` uses |
| `@keyframes` | 62, in 11 files |
| Distinct values | 56 font sizes, 50 border radii, 71 box shadows, about 45 durations |
| Fonts | Fredoka and Nunito, loaded from Google Fonts at runtime |
| Reduced motion | Honoured in only 4 files |

## Repeated templates

- Answer buttons were styled six separate ways: `lesson-choice`, `cookie`,
  `treasure-option`, `missing-choice`, `story-answer` and `word-tile`.
- Every game's start screen was the same centred card: an emoji in a circle, a
  dashed quote box, three chips and a big green button. That green belonged to
  neither palette.

## Chrome

- Inside an app there were two header bars.
- Stars, mute and the voice indicator each appeared twice.
- There were four ways home.

## What read as AI-made

- The home screen's purple-to-pink gradient with blurred blobs.
- Gradient squircle icons.
- Emoji lanterns and emoji icons on tiles.
- "Choose your adventure" style badges.
- The one template used on every start screen.
