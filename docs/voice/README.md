# Luna's voice

How Luna should sound, and what's been learned getting her there. For how
the voice is built (Kokoro, pre-rendered clips, `npm run voice:render`), see
`scripts/voice/` and the `know-how` skill.

| Read | For |
|---|---|
| [sound-standard.md](sound-standard.md) | How each phonics sound should sound: the teachers' rules, what each sound must never sound like, and where Luna is today. The reference every round of the Sound Check is judged against. |
| [research-2026-10-28.md](research-2026-10-28.md) | The first research run: why today's letter sounds fall short, measurements against real American speech, the Chatterbox bake-off, the voice-conversion test, whether Alex should record the sounds, and the decisions before round 3. |

The work itself is the VOX epic (`kanban/epics/VOX.md`). The scripts behind
the Sound Check rounds and the research are in
`.claude/skills/know-how/voice-audit/`. The Sound Check page, where Alex
picks, is an artifact; its link is in Claude's memory, not here, since the
repo is public.
